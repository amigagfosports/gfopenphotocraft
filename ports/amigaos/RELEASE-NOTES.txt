GFOpenPhotoCraft 0.1.0 RC1
==========================

This is a native AmigaOS 3.x 68040 qualification build of PhotoCraft.

Install by unpacking `GFOpenPhotoCraft-0.1.0-rc1-68040.lha`, placing the
PhotoCraft drawer where wanted, and starting `PhotoCraft` from Workbench.

Working in this build:
- native GFOpenLayout editor window;
- bounded RGBA raster and layer model;
- New, Add Layer and Show/Hide Layer;
- Invert, Grayscale, Brighter and Darker;
- one-step pixel Undo and Redo;
- live composited pixel preview.
- bounded PCF1 Save and Open at SYS:PhotoCraft.pcf;
- fail-closed PCF1 parsing for truncated, malformed and trailing data.

Not yet qualified:
- ASL file requesters and IFF/DataTypes import/export;
- pointer brush painting;
- upstream egui interface or full .pcraft compatibility;
- updater installation path.

The 21 November isolated-68040 run qualified launch, Grayscale, Undo, Redo,
live preview redraw and close-gadget return to Workbench in the earlier Q1
binary. The exact RC1 Save/Open and hostile-file receipt is recorded in
NATIVE-UAT-20261122.md and the independent Kitchen job attached to the Forge
pull request.
